---

Dograh platform supports ElevenLabs, OpenAI, Google, Azure Speech, Deepgram, Cartesia, Smallest AI, MiniMax, Sarvam, Soniox, Rime, Inworld, Camb.ai, xAI, LMNT, and Dograh TTS engines. There are some voices from the providers that we ship by default. You can refer to the providers API documentation to select a voice ID that's most relevant for your language requirement.

<Warning>
Voice providers receive the data needed to synthesize speech, such as generated text, selected voice, model settings, and request metadata. Review the provider's data processing, retention, model training, and regional hosting policies before using sensitive data.
</Warning>

For locally deployed or self-hosted TTS models, Dograh also supports Speaches, an OpenAI API-compatible server for speech generation.

### Soniox

[Soniox TTS](https://soniox.com/docs/tts) streams speech over WebSocket with a single voice catalog that works across all 60+ supported languages, so one voice can answer in English, Hindi or Gujarati without changing configuration. Create an API key in the [Soniox Console](https://console.soniox.com) and pick **Soniox** as the voice provider.

| Setting | Notes |
| --- | --- |
| `model` | `tts-rt-v2`. |
| `voice` | A built-in voice name (e.g. `Adrian`, `Priya`, `Arjun`, `Meera`) or the UUID of a cloned voice from your Soniox project. |
| `language` | ISO 639-1 code of the primary language (`en`, `hi`, `gu`, …). Mixed-language text switches naturally within a sentence. |
| `speed` | 0.7–1.3 speech-rate multiplier. |

If you don't find your favourite voice, you can always add the voice ID manually.
